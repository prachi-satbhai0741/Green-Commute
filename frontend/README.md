# GreenCommute frontend

Next.js 16 / React 19 with TypeScript and vanilla CSS. See the [project README](../README.md) for setup, configuration, features, estimates, and deployment.

`npm run dev` starts port 3000; `npm run lint` checks sources; `npm run build` creates the production build; `npm start` serves it. `/api` is proxied to the configured `API_URL`.
